# Polish pass, 2026-10-12

Method: Impeccable's deterministic detector (prebuilt in-page bundle from the vendored repo) was loaded
on the running app with the demo database and run on every screen (Overzicht, Prognose, Vaste lasten,
Upload, Budget), phone width, Light and Dark +. Then a manual audit with the audit/critique/harden/clarify
method docs in `.claude/skills/impeccable/reference/`.

## Found and fixed

- **`text-accent-ink` did not exist as a Tailwind colour.** Primary buttons, the active tab and the badge
  had dark text on a dark blue fill in Light (1.4:1 to 1.5:1). Added `--color-accent-ink`. After the fix the
  detector reports no findings on any screen in Light and Dark +.
- Messages that reach the screen were English; translated (they move to the i18n layer next).
- Upload summary showed a raw month; it now shows the period, and lists skipped rows with the reason.
- Settings page: back-up (full JSON, transactions CSV with formula protection) and rule management.

## Not done in this pass

- Dark (plain) and the laptop width were not scanned; the tokens are shared with Dark + and the layout uses the same components.
- Restoring from a back-up file.
- Real bank balance on the Prognose line (needs the parsers to store it).

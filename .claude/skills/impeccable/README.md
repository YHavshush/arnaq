# Impeccable (guidance only)

Vendored from https://github.com/pbakaus/impeccable (Apache-2.0, see LICENSE and NOTICE.md), version 4.5.2.

Only the markdown method docs for the commands used in milestone 8 are kept: `audit`, `critique`,
`harden`, `clarify`, `polish`, `adapt`, `optimize`, `onboard`, `layout`, `typeset`, `distill`, `quieter`.
They are read as a checklist, not run as a skill: the official installer downloads and executes a
platform binary and installs edit hooks, which this repo does not use.

The deterministic detector (59 rules) was run in the page: the prebuilt in-page bundle from the same
repo was loaded on the running dev server, on the demo database, and its findings were fixed. See `docs/polish/`.
